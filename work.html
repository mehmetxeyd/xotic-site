Case 01 · Solana · 2026

Credential revocation on Solana

Checking whether a certificate has been revoked usually means asking a server, through a CRL download or an OCSP responder. If that server is down, verifiers either fail or skip the check. This prototype moves revocation status onto Solana. Anyone can check it publicly, with no server to run and no wallet needed.

  • Rust
  • Anchor
  • Solana
  • Ed25519
  • @solana/web3.js
  • PKI
Live demo ↗ Source ↗
  1. 01 — Issue

    The issuer's wallet signs a small JSON credential with its Ed25519 key. The wallet's public key is the trust anchor, and nothing is stored on-chain yet.

  2. 02 — Revoke

    One transaction to the Anchor program creates a record at an address derived from issuer + SHA-256(credential). Only the issuer's signature can create it.

  3. 03 — Verify

    Anyone checks the signature, then looks up the derived address. If the record exists, the credential is revoked, and the record also stores when.
